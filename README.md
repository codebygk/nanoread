# Nanoread - AI Webpage Summarizer

A clean and fast web app that summarizes any webpage using AI. Paste a URL and get the summary in seconds.


Live app: [https://nanoread.vercel.app](https://nanoread.vercel.app)

---

## Features

- Paste any public URL and summarize articles, docs, wikis, and blogs.
- Multi-provider support: OpenAI, Groq, Ollama, OpenRouter, LM Studio, Together, and any OpenAI-compatible API.
- Bring your own API key so your data stays in your browser.
- Light and dark theme support with automatic system preference detection.
- Local browser history saves the last 20 summaries for quick reference.
- No backend storage: summaries and keys are never logged or stored server-side.

## Requirements

- Modern browser with JavaScript enabled.
- Internet access to load the app and fetch webpage content.
- OpenAI-compatible API key or provider credentials.

## Usage
1. Open the app at [https://nanoread.vercel.app](https://nanoread.vercel.app).
2. Paste the webpage URL you want to summarize.
3. Click the summarize button.
4. Review the clean summary with key points and takeaways.
5. Use the history panel to revisit recent summaries.
